# Identidade ROMUS

SVGs originais fornecidos por Douglas, preservados sem alteração. As versões sem sufixo usam tinta clara para superfícies escuras; as versões `-dark` usam tinta escura para superfícies claras.

A paleta e a composição seguem as referências fornecidas. A fonte Inter é distribuída localmente sob a licença SIL Open Font License, incluída em `../fonts/OFL-Inter.txt`. Fonte: https://github.com/google/fonts/tree/main/ofl/inter .

O ícone ICO do Windows é gerado dos SVGs pelo script `scripts/brand-icons.cjs`. A interface usa os SVGs diretamente.
